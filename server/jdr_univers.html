Dans le JDR basé sur l'univers d'Eden Eternal, les lancés de dés pour des actions se jouent au D20.

Voici les 2 règles à suivre pour créer votre personnage :

  • le personnage doit rejoindre pour une vraie raison le groupe (cohérente/roleplay) , et être lui-même cohérent dans son être.
  • Le personnage ne peut pas avoir un rôle trop important dans l'univers d'Eden (ex : chef, politicien, méga mage, etc...).
